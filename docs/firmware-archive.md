# Historical Firmware Archive

[Back to the development guide](../README.md)

The original repository preserved files after the vendor website and forum closed. Images and tools remain available from [GitHub Releases](https://github.com/Gao-OS/JingPad-Files/releases).

This is a historical archive index; it does not mean every image was tested on the current C1. The device already runs JingOS Linux, and installing software does not require reflashing. Flashing across models requires separate checks of the partition layout, boot chain, and calibration backups.

The original README description is preserved below:

> Some files useful for JingPad since Jingling took down the webside and the forum.

## What's in the box?

All the files saved on a drive include:

- Jingpad A1 Linux rom
- Jingpad C1 Android rom
- Jingpad C1 UserDebug Android rom (Gapps flashable)
- A save of the boot loader unblocker from deadman96385
- Instructions to flash Gapps
- Jingpad Flash tool
- Compatible openGapps and NickGapps
